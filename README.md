# 📊 Data Analysis Portfolio

Welcome to my data analysis portfolio! This repository contains several end-to-end data analysis projects using **Python**, **MySQL**, and **Power BI**. Each project includes datasets, detailed notebooks or SQL scripts, and well-documented insights derived from real-world data.

---

## 🔍 Featured Projects

### 1. 🏥 Medical Appointment No-Show Analysis
**Objective:**  
Identify key reasons why patients fail to show up for their scheduled medical appointments.

📁 Dataset included in `datasets/` folder.

**Key Insights:**  
- Long waiting times negatively impact attendance.  
- Scholarship eligibility and alcoholism influenced no-show behavior.  
- SMS reminders had limited effectiveness.

---

### 2. 🍕 Pizza Sales Analysis
**Objective:**  
Analyze pizza sales and ingredient usage to uncover top-performing products and improve inventory management.

📁 Dataset included in `datasets/` folder.

**Key Insights:**  
- A few pizza types contributed the most revenue.  
- Ingredient demand patterns helped optimize inventory.  
- Sales peaked on weekends and during specific hours.

---

### 3. 🛒 Maven Market Retail Analysis
**Objective:**  
Evaluate regional sales performance, product returns, and customer purchasing behavior using transactional retail data.

📁 Dataset included in `datasets/` folder.

**Key Insights:**  
- Top stores and regions identified via Power BI dashboards.  
- Return rates flagged problem products.  
- Seasonal trends helped uncover revenue patterns.

---

### 4. 🎵 Spotify Track Performance & Audio Features
**Objective:**  
Explore how audio features like tempo, energy, and danceability relate to track popularity across platforms (Spotify, Apple Music, Shazam).

📁 Dataset included in `datasets/` folder.

**Key Insights:**  
- High danceability and energy linked to streaming success.  
- Platform-wise trends revealed varying listener preferences.

---

### 5. 📂 Portfolio Project – MySQL-Based Analysis
**Objective:**  
Perform SQL-based data analysis on a relational database containing customer, transaction, product, and return data.

📁 Dataset included in `datasets/` folder.

**Key Insights:**  
- Identified top revenue-generating segments and regions.  
- Analyzed return behavior by category and geography.  
- Generated SQL-based KPIs and visualized them using Power BI.

## 🧰 Technologies & Tools

- **Languages:** Python 3, SQL (MySQL)  
- **Libraries:** pandas, numpy, matplotlib, seaborn  
- **BI Tool:** Power BI  
- **Environment:** Jupyter Notebook, MySQL Workbench, VS Code

## 🗂️ Project Workflow

Each project follows a consistent pipeline:

1. **Data Understanding** – Schema, column descriptions, and datatypes  
2. **Data Cleaning & Transformation** – Handling nulls, feature engineering  
3. **EDA (Exploratory Data Analysis)** – Visualizations and correlation analysis  
4. **Insights & Conclusions** – Business recommendations based on findings  
5. **Dashboarding (Optional)** – Power BI visual summaries
